# Tableau-Coffee-Shop-Customer-sales-decision-impacting-dashboard
  
Coffee Roasters Analytics is an interactive Tableau dashboard project built to analyse sales, customer activity, product performance and time-based trends for a coffee retail business.

The dashboard was designed to provide a clear executive view of business performance while also allowing users to drill into detailed product, customer and trend insights.

 Key Features

- Interactive KPI views for Sales, Customers and Quantity
- Dynamic dimension and measure selection using Tableau parameters
- Product performance analysis using horizontal bar charts
- Treemap visualisation for category contribution
- Weekly trend analysis
- Year-over-Year trend comparison
- Dynamic date filtering
- Interactive dashboard navigation
- Custom calculated fields for multi-measure analysis
- Conditional formatting and dynamic labels



Product Performance

The dashboard allows users to switch dimensions and measures dynamically to compare product categories such as:

- Beverages
- Food
- Whole Bean / Teas
- Merchandise
- Add-ons

Users can analyse metrics such as quantity and other selected business measures.

Treemap Analysis

A dynamic treemap highlights the contribution of each product category to the selected measure.

This helps quickly identify dominant categories and areas with lower contribution.

Weekly Trend Analysis

The weekly trend visual combines:

- Weekly performance
- Percentage change
- Trend indicators
- Period-to-period comparison

This provides a clearer view of fluctuations, growth patterns and unusual changes in business performance.

Year-over-Year Trend

The YOY trend chart compares performance across months to identify:

- Seasonal patterns
- Growth or decline
- Peak periods
- Changes in customer or sales behaviour

Data Model

The Tableau data model was created using multiple related tables connected through Tableau relationships and joins.

The model includes datasets such as:

- Calendar
- Customer Lookup
- Employee Lookup
- Food Inventory
- Product Lookup
- Sales by Store
- Store Lookup

Tables were connected using Tableau's relationship model ("noodles") where appropriate, with joins used where a more direct row-level connection was required.

This approach helped maintain the correct level of detail while supporting analysis across multiple business dimensions.
